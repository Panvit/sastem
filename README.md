sasteam — Мессенджер

sasteam — это десктопный мессенджер с современным графическим интерфейсом на базе библиотеки CustomTkinter и серверной частью для сетевого взаимодействия.

🛠 Технологии

Клиентская часть: Python 3.x, customtkinter

Серверная часть: python (socet)

Система контроля версий: Git / GitHub

🚀 Установка и запуск

Для полноценной работы мессенджера необходимо настроить и запустить как серверную, так и клиентскую части.
2. Настройка и запуск Сервера (Visual Studio)

Откройте Visual Studio.

Выберите File > Open > Project/Solution (Файл > Открыть > Проект/Решение) и откройте файл проекта сервера.

Соберите проект (Build Solution / Ctrl + Shift + B).

Запустите сервер нажатием клавиши F5 или кнопки Start.

💡 Примечание: Убедитесь, что сервер успешно запущен перед подключением клиента.
